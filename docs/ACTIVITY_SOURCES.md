# 활동 페이지 출처와 공개 판단

최종 갱신: 2026-07-18

활동 페이지는 날짜나 성과 수치를 만들지 않고, 공개 허용된 네 프로젝트와 포트폴리오 자체에서 반복 확인되는 작업 주제만 묶는다. 원본 로그, 내부 경로, 비공개 저장소명은 화면에 표시하지 않는다.

| 활동 주제 | 확인 근거 | 공개 범위 | 판단 |
| --- | --- | --- | --- |
| 교육 현장 관찰 | 입시 상담 보조 시스템의 지원 자격·상담 흐름, AI 수업 설계 덱의 연수 흐름 | 문제를 관찰하고 판단 지점을 구조화한다는 작업 방식 | 공개 가능 |
| Flask 웹앱 설계 | 입시 상담 보조 시스템과 생성형 AI 계정 운영 도구의 Flask 앱 구조 | 역할·데이터·승인 흐름을 작은 서버 렌더링 서비스로 구성 | 공개 가능 |
| 자동화 워크플로 | 연수자료 제작의 조사·승인·시험·검수 흐름, 교육 덱의 콘텐츠 검증 | 입력·승인·실패 조건을 문서와 검사로 남기는 방식 | 공개 가능 |
| 인프라와 배포 | 공개 후보의 컨테이너·배포 구성과 이번 포트폴리오의 루프백·프록시 분리 | 특정 운영 성과 없이 배포 경계를 준비한다는 수준 | 공개 가능 |
| 검증과 품질 | pytest, 콘텐츠 검증, 정적 빌드, 접근성·브라우저 QA 절차 | 테스트·접근성·문서로 결과를 확인한다는 방식 | 공개 가능 |

## 제외한 내용

- 개인 경력 연도, 소속, 고객명, 사용자 수, 개선율은 근거가 없어 사용하지 않는다.
- 분류 자료의 저장소 개수와 내부 점수는 방문자에게 의미 있는 활동이 아니며 공개하지 않는다.
- 실제 학생·교사·계정·예약·상담·슬라이드 데이터는 사용하지 않는다.
- 프로젝트 외부 링크와 화면 캡처는 응답·소유권·공유 범위·권리 검토가 끝날 때까지 넣지 않는다.

## 템플릿 규칙

- 각 항목은 주제, 설명, 연결 가능한 공개 프로젝트만 표시한다.
- 날짜가 없는 주제 흐름이므로 `time` 요소를 허위로 사용하지 않는다.
- 활동은 헤더·푸터의 상시 링크와 홈의 `활동 기록` CTA로 접근 가능해야 한다.
