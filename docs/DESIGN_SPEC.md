# 디자인 명세

최종 갱신: 2026-07-18
상태: 구현 기준 확정

## 방향

한국어 편집형 기술 포트폴리오다. Material의 명확한 계층·상태와 Apple의 여백·절제를 결합하되 어느 브랜드의 화면도 복제하지 않는다. 핵심 시각 문법은 `문제 → 판단 → 결과 → 개선`을 잇는 정밀한 블루프린트 경로다. 카드를 반복하지 않고 열린 행, 얇은 구분선, 전체 폭 밴드, 세로 레일로 내용을 조직한다.

## 콘셉트 기준

- `docs/design-v2/home-desktop-concept.png`: 홈 전체 리듬과 첫 화면
- `docs/design-v2/projects-desktop-concept.png`: 필터와 열린 프로젝트 행
- `docs/design-v2/project-detail-desktop-concept.png`: 상세 정보와 판단 레일
- `docs/design-v2/activity-desktop-concept.png`: 주제 기반 활동 경로
- `docs/design-v2/about-desktop-concept.png`: 역량·기술·작업 방식

이미지 생성 결과의 잘못된 기술명, 연도, 프로젝트 수, 외부 링크는 시각 배치 예시일 뿐 콘텐츠 근거가 아니다. 공개 데이터는 `docs/REPOSITORY_VERIFICATION.md`가 우선한다.

## 타이포그래피

- 기본: `Pretendard`, `Noto Sans KR`, `Apple SD Gothic Neo`, `Inter`, `system-ui`, `sans-serif` 순서의 로컬 폴백. 외부 폰트 요청은 만들지 않는다.
- 대표 제목: `clamp(2.75rem, 5vw, 5rem)`, 750~850, 행간 1.08~1.16, 자간 `-0.05em` 안팎.
- 섹션 제목: 1.25~2rem, 720~800.
- 본문: 1rem~1.125rem, 행간 1.65~1.8.
- UI/라벨: 0.75~0.95rem, 650~800. 버튼·입력도 명시적으로 글꼴과 크기를 지정한다.

## 간격·표면

- 4, 8, 12, 16, 24, 32, 48, 64, 80, 112px 간격 스케일을 사용한다.
- 섹션은 얇은 선이나 배경 밴드로 전환한다. 모든 내용을 둥근 카드에 넣지 않는다.
- 반경은 버튼과 입력에서 4~8px, 모바일 메뉴에서 최대 8px로 제한한다.
- 그림자는 모바일 메뉴 등 겹침을 설명해야 하는 곳에만 한 번 사용한다.

## 컴포넌트

- 헤더: 브랜드, 홈/프로젝트/활동/소개. 현재 경로는 코발트 밑줄과 `aria-current`로 표시한다.
- 모바일 메뉴: 44px 이상 버튼, 열림 상태 `aria-expanded`, 열 때 첫 링크로 포커스 이동, Escape와 바깥 클릭으로 닫기, 닫은 뒤 토글로 포커스 복귀.
- 버튼: 채움 코발트와 윤곽 코발트 두 변형. 화살표는 일관된 inline SVG를 쓴다.
- 프로젝트 행: 제목·요약·분야·성숙도·기술을 열린 행에 배치하고 전체 행은 상세 링크다. 모바일은 단일 열로 재배치한다.
- 필터: 서버 쿼리 파라미터가 기본 동작이다. JavaScript는 입력 변화·결과 수 안내를 점진적으로 향상한다.
- 블루프린트: CSS 선과 작은 원형 노드, 필요한 최소 SVG. 장식이 핵심 콘텐츠를 가리지 않는다.
- 활동 경로: 시간·날짜를 만들지 않고 검증된 다섯 주제를 하나의 세로 경로로 연결한다.
- 푸터: 짙은 잉크 배경, 상시 탐색과 GitHub 프로필 링크.

## 카피 잠금

홈 첫 화면에서 허용하는 가시 카피는 브랜드와 탐색 외에 다음뿐이다.

- `교육의 문제를 기술의 구조로 바꿉니다.`
- `현장의 반복 업무를 살피고, 검증 가능한 웹 서비스와 자동화 흐름으로 설계합니다.`
- `프로젝트 보기`
- `활동 기록`

hero eyebrow, kicker, badge, 가짜 지표는 추가하지 않는다.

## 아이콘

- 메뉴/닫기, 화살표, 검색, 외부 링크에만 1.75~2px 둥근 선의 코드 내 SVG를 쓴다.
- 이모지는 UI 아이콘으로 사용하지 않는다.
- 시각적 의미가 라벨로 충분하면 아이콘을 추가하지 않는다.

## 모션·접근성

- hover 이동은 2~3px, 180ms 안팎으로 짧게 제한한다.
- 블루프린트 경로는 최초 1회 1.4초 이하로 그릴 수 있다.
- `prefers-reduced-motion: reduce`에서는 모든 비필수 모션과 부드러운 스크롤을 제거한다.
- 가시적 `:focus-visible`, 건너뛰기 링크, 의미론적 제목 구조, 44px 터치 영역, 상태 텍스트를 제공한다.

## 반응형

- 1000px 이하: 영웅과 상세 두 열을 한 열로 전환하고 프로젝트 보조 열을 줄인다.
- 760px 이하: 20px 여백, 단일 열, 모바일 메뉴, 44px 이상 제어, 프로젝트 열린 행, 왼쪽 활동 레일을 적용한다.
- 단순 축소하지 않고 제목, 메타 정보, CTA, 레일의 순서를 재배치한다. 360px에서 가로 스크롤이 없어야 한다.
